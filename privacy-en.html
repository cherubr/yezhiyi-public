Yezhiyi · Privacy and data

Updated: 19 November 2026 · Source version 1.0.3

Yezhiyi processes webpages and PDFs on your device. Text you translate is sent directly to your chosen translation service. PDF files and page images are not sent to that service. API keys stay on this device; general preferences may sync through Chrome. The extension includes no analytics or advertising code.

Webpage text

Clicking the floating button, a keyboard shortcut, a paragraph translation gesture, or a context-menu command starts the relevant translation. Automatic translation is off by default; when enabled, eligible visible text is sent automatically. Active page translation also handles new visible content. New requests pause while the page is hidden. Canceling ends that page's session.

Password fields, input values, editable areas, and protected code or formula content are excluded from whole-page translation. Open Shadow DOM and accessible frames follow the same collection rules. Closed Shadow DOM is not read. Translation requests do not deliberately include the page URL, browsing history, or entire page HTML. The selected text itself may contain names, links, account details, or other private information, which will be sent with the text.

PDFs, OCR, editing, and export

Local PDFs are opened on this device. Online PDFs are retrieved directly from an authorized source, up to 50 MiB. These requests omit cookies and Referer headers and reject redirects. The source server still receives the requested URL, IP address, and normal connection metadata. For protected or redirected files, download them first and open locally. Document passwords are used in memory for this opening only.

Starting PDF translation extracts text and runs OCR locally where needed. Only eligible extracted text and language parameters go to the translation service. Complete PDF bytes, page images, and OCR bitmaps are not uploaded. Layout, manual revisions, independent editor drafts, and export run locally. Saved drafts may contain images extracted from the page or inserted by you.

Changing reading modes, zoom, and rotation reuses existing results. Explicitly translating missing pages or translating again sends the corresponding text. Export does not change the source file or itself start new OCR or translation. Exported PDFs are separate files you manage.

Recipients and downloads

There is no Yezhiyi translation relay server. The background worker connects directly to Google Translate, MyMemory, Baidu, or the selected AI endpoint. Providers set their own data retention, model-training, billing, and privacy policies. Configure a local Ollama server if you wish to send translation text to a local endpoint. Every network recipient can see normal connection metadata, including your IP address.

English and Simplified Chinese OCR models are bundled. Other supported language models and export fonts download from fixed sources when needed, after source permission is granted. Downloads are checked against expected size and SHA-256 and stored locally. The download host receives the resource request and normal network metadata, not your PDF pages. Provider websites opened for documentation or credentials are governed by their own policies.

This privacy page, when hosted on GitHub Pages, connects to GitHub's hosting service under its logging policies. It uses no tracking scripts, remote fonts, or external executable code.

AI prompt templates and testing

Prompt templates stay on this device and do not use Chrome Sync. AI translation requests include the selected preferences and additional instructions, alongside source text, to your chosen AI service. The entire template library is not uploaded. Local previews send no requests. Clicking the translation test or comparison button sends test text and instructions and may incur API charges. Test text and results remain only in the current settings page memory and are excluded from template exports.

Storage and synchronization

  • Local Chrome storage: AI endpoint, model and key settings; Baidu credentials and verification records; per-service rate and concurrency policies; custom glossary rules; AI prompt templates, favorites, the default template, and up to five historical versions per custom template. These are not written to Chrome Sync.
  • Chrome Sync preferences: selected service/provider, source and target languages, interface language, themes and color mode, translation typography, automatic/hover translation preferences, floating menu preferences and position, and shortcut enablement. These contain no document content or API keys, but may sync to devices using the same Chrome account.
  • IndexedDB: saved in-place revisions, independent translation drafts (potentially including images), downloaded OCR models, and downloaded export fonts. Legacy revision data may be read for compatibility.
  • Local storage: PDF thumbnail sidebar visibility and reader split ratio.
  • Memory: page source snapshots, translations, current PDF bytes, OCR and reading/export caches. The shared background translation cache holds at most 256 entries; successful results expire after ten minutes, failed-request cooldown is thirty seconds, and background shutdown clears it. Closing the PDF reader releases its in-memory document state.

Older versions stored credentials in Sync. Migration prefers existing local settings, copies legacy credentials locally, and removes legacy Sync fields only after a successful local write. The extension cannot control historical copies retained by Chrome's synchronization service.

Browser permissions

  • Site access and content scripts: collect eligible text and display translation controls on sites allowed by Chrome.
  • Fixed service hosts: translation requests and connection tests, including loopback Ollama endpoints.
  • Optional HTTP/HTTPS hosts: request access to a custom AI host, online PDF source, or model/font download source when you invoke that action. Refusing permission blocks the request. Revoke access in Chrome extension settings.
  • storage: local configuration and eligible synchronized preferences.
  • contextMenus: translate a page or selected text when you invoke a menu item.
  • tabs: address the active tab and open extension settings or the PDF reader.
  • webNavigation: verify document identity, restore navigation sessions, and route frame-specific paragraph gestures. Document identities remain in memory; browsing history is not stored or uploaded.

What we do not do

  • No advertising, usage analytics, or telemetry code, and no data-collection server of our own.
  • No collection of account identity, names, email addresses, device identifiers, or location; the extension has no registration or sign-in.
  • No reading or uploading of browsing history, cookies, bookmarks, or download records.
  • No upload of complete PDF files, page images, OCR bitmaps, or whole-page HTML.
  • No remote executable code; translation and PDF engines ship inside the package, and what downloads on demand is model and font data.
  • No deliberate inclusion of the page address in translation requests, and no bulk export of your glossary to a service.

Exceptions you should know about: the service you choose processes the text and normal connection metadata under its own policy; Chrome Sync transmits ordinary preferences according to your account settings; GitHub Pages records access to this page under its hosting rules. These are outside the extension's control.

Logs, security, and retention

Development diagnostics use task stages, counts, timing, status codes, and service identifiers. They must not record source/translated text, credentials, or sensitive request information. Release preparation disables extension logging in its temporary release copy. Runtime messages use Chrome-provided sender identity, and translation results are checked against cancellation and configuration generations.

Local storage is not an encrypted vault. Someone with access to your device or browser profile may access locally stored configuration and drafts. Use appropriate device security. Custom remote APIs require HTTPS; HTTP is limited to supported loopback endpoints. These controls cannot guarantee a third-party provider's behavior.

Saved configuration, drafts, revisions, models, and fonts do not expire automatically. They remain until deleted or the extension is uninstalled. Downloaded models/fonts can be managed in the reader; credentials and glossary entries can be edited or cleared in settings. Closing a page does not delete saved drafts. You manage separately exported glossary JSON and PDF files yourself. Provider-held data must be handled under that provider's deletion policy.

Items still to be confirmed

The following cannot be verified from the source code. They are policy or operating decisions and are not decided. This page makes no promise about them; update this document and the date above once they are decided.
  • Effective date and policy version: only the document update date is shown; no effective date is set.
  • Canonical address of this page: it is published after the public documentation site is configured, and the address in use depends on the maintainer's deployment and the store listing. Keeping or migrating an older address is a separate decision.
  • Developer contact channel: only the project's public issue tracker exists today; there is no dedicated privacy email or form.
  • Link to this page inside the extension: the About panel in settings currently shows an inline privacy summary only, with no link to this page.
  • Third-party policy links: services are listed by name, without their privacy-policy URLs, to avoid publishing unverified links.
  • Minors and sensitive personal information: the extension performs no age gating, and no policy statement yet says whether it is intended for minors or advises against sensitive content.
  • Retention and deletion commitments: local data does not expire automatically. Whether to add a single control that clears all local data, or to state a retention period, is undecided.
  • Copies held by Chrome Sync: the extension cannot delete historical copies kept by the synchronization service, and account-side cleanup guidance is undecided.
  • Governing law and complaints: the applicable jurisdiction, compliance baseline (for example GDPR or China's PIPL), and complaint handling are undecided.
  • Project license: the source repository has no license file for the project itself yet; bundled third-party resources keep their own licenses.

Your choices and contact

Leave automatic translation disabled, choose individual paragraphs or selections, cancel active tasks, change services, revoke site permissions, manage downloaded resources, or uninstall the extension. Change the interface language independently of the translation target. For questions, use the public issue tracker. Do not include keys, private documents, or unredacted requests.
