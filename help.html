页知译 · 使用帮助

开始使用

从维护者提供的安装入口取得扩展。首次使用打开设置页选择服务；Google 和 MyMemory 无需填写账号，百度需当前凭据测试通过，AI 服务需自己的连接配置，本机 Ollama 需先启动服务。

网页翻译

点击悬浮球开始或取消翻译；鼠标停在悬浮球上会展开弧形菜单，可打开翻译控制、PDF 阅读器、设置与反馈，鼠标在悬浮球与菜单之间移动不会收起。鼠标停在段落上按 Shift 可翻译或还原单段。悬浮球可拖动停放，右侧空间不足时临时左移，菜单收起后归位。

翻译提示只在快捷键已设置且已启用时显示实际按键组合，未设置时不显示。扩展建议为 Ctrl+Shift+Y，macOS 为 Command+Shift+Y，可在浏览器扩展的键盘快捷键页面调整。

关闭自动翻译只影响新页面自动启动；已启动的页面需主动取消才停止补翻。浏览器内置页面、封闭式 Shadow DOM 及受限框架可能无法处理。

界面语言与外观

界面语言支持简体中文、繁体中文与英文，在“界面设置”中独立选择，不影响译文的目标语言；其他浏览器界面语言回退英文。外观模式可跟随系统、固定浅色或固定深色，主题配色共 13 种，默认为午夜青蓝，明暗版本完整配套，仅作用于扩展界面，网页与文档保持原色。

“显示样式”单独控制双语或仅译文显示，以及译文的字体、字号、颜色、字重、行高与段落间距，可实时预览。

PDF 阅读与导出

从弹窗或设置页的翻译工具打开 PDF 阅读器。在线文件需最终直链及来源授权；需要登录或跳转的文件请下载后从本地打开。

“停止翻译”保留成功结果；“取消翻译”清除本页原位译文与修订；“重新翻译”清除当前页旧结果再翻译。独立编辑稿分别保存。

自动译文导出包含已保存的原位修订，不包含独立编辑稿。要保留独立编辑器改动，请使用“导出本页编辑稿”。复杂结构或缺字可能导致回退或阻止导出。

报告问题

在公开 Issues选择问题类型，提供扩展版本、Chrome 版本、系统、重现步骤、预期结果与实际结果。可先用不含隐私的最小示例验证。

不要上传 API Key、私人 PDF、完整请求或未脱敏日志。用户反馈与内部开发任务分开维护，公开仓库不包含源码。
