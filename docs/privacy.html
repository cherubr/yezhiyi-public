页知译 · 隐私与数据说明

文档更新日期：2026 年 11 月 17 日 · 依据源码版本 1.0.3 核对

本说明适用于“页知译 · 网页双语翻译”Chrome 扩展，说明网页翻译与 PDF 阅读翻译如何处理数据。可用功能以您安装的版本为准；上方日期是本文档的修订日期，正式生效日期见待确认事项。

要点：需要翻译的网页或 PDF 文字会直接发送给您自己选择的翻译服务，扩展没有自建翻译中转服务器。PDF 文件、页面图像、OCR 识别与导出排版全部在您的设备上完成。API 密钥、术语表、请求策略与 PDF 人工修订只保存在本机；语言、显示样式等普通偏好可能通过您的 Chrome 账号同步。扩展不含广告、使用行为统计或遥测代码。

一、网页文字如何处理

  • 只有在您主动操作（整页翻译、选中文字翻译、Shift 单段翻译、悬停翻译）或开启“自动翻译”后，符合采集规则的文字才会发送。发送内容为：待翻译文字、源语言、目标语言，以及所选服务需要的参数。
  • 新安装默认关闭自动翻译，旧用户已保存的偏好不会被强制覆盖。开启自动翻译或主动开始当前页翻译后，滚动、弹框与动态更新可能触发补翻，从而继续发送新出现的文字。
  • 单段翻译默认要求鼠标停在段落上并按 Shift。若在设置中改为“直接触发”，鼠标停留本身就可能触发文字发送；也可完全关闭悬停翻译。
  • 自动与整页采集会跳过：输入框的值、密码框、textarea、select、可编辑区域、代码区、不可见内容，以及网页明确标记禁译的区域。主动 Shift 翻译可以覆盖网页的 translate="no" 等禁译标记，但仍然跳过输入值、编辑区与代码。
  • 开放式 Shadow DOM 与 Chrome 允许访问的 iframe 使用同一套采集规则，由主页面统一开始或取消。扩展不读取封闭式 Shadow DOM 内部内容。
  • 翻译请求中不包含当前网页地址、浏览历史或整页 HTML。但正文本身可能含有网址、姓名、账号或其他私人信息，这些内容会随文字一起发送。请按需选择翻译范围，避免发送不希望交给服务方的内容。
  • 为合并请求与减少重复调用，原文与译文会短暂驻留在扩展后台内存和当前页面内存中，详见第四节。

二、PDF 文件、OCR 与导出

  • 本地 PDF 在扩展内读取，不上传文件本身。在线 PDF 从您输入或打开的地址直接获取，并先按该来源申请访问权限；单文件上限 50 MiB。
  • 在线 PDF 请求不携带 Cookie、不发送 Referer（来源页）请求头、不跟随重定向。来源服务器仍会收到文件地址中的路径与查询参数，以及 IP 地址等通常的网络连接信息。需要登录或跳转的文件请先下载，再从本地打开。
  • 加密 PDF 的密码在阅读器弹框中输入，仅用于本机解锁文档，不保存、不发送。
  • 主动开始翻译后，扩展提取可用文字，并对扫描页或图文混排区域在本机运行 OCR。完整 PDF、页面图像与 OCR 位图不发送给翻译服务；只有需要翻译的提取文字与语言参数会发送。
  • 原位译文显示、独立译文编辑、人工修订与 PDF 导出均在本机完成。拖画文字框修订只提取本页文字与坐标，不主动发起翻译请求；切换阅读模式、缩放与旋转复用已有结果，不重新发送文字。显式补译或重新翻译会发送相应文字。
  • 导出不修改源文件字节，不触发新的翻译或 OCR。导出的 PDF 是您设备上的独立文件，由您自行保管或删除。
  • 英语与简体中文 OCR 模型随扩展提供。其他已支持语言模型（繁体中文、日语、韩语、法语、西班牙语、德语、俄语、阿拉伯语）与中日韩导出字体按需下载，详见第三节。

三、哪些服务会接收数据

翻译服务

扩展没有自建翻译中转服务器。文字由扩展后台直接发往您选择的服务；服务方的数据保留、模型训练、计费与其他处理规则由其自行决定，请查阅所用服务的隐私政策。任何网络请求都会向接收方暴露 IP 地址等通常的连接信息。

各服务的实际请求方式与发送内容（依据当前源码）
服务请求方式发送内容凭据处理
Google 翻译 HTTPS GET，文字位于地址查询参数 待翻译文字、源语言、目标语言 无需账号或密钥
MyMemory HTTPS GET，文字位于地址查询参数 待翻译文字、明确的语言对 无需账号或密钥
百度翻译 HTTPS POST 表单 文字、源/目标语言、AppID、随机盐值、签名 密钥本身不发送，只发送由 AppID、文字、盐值与密钥计算的 MD5 签名
AI 服务（OpenAI、DeepSeek、通义千问、智谱、Kimi、火山方舟、MiniMax、阶跃星辰、硅基流动、百度千帆、魔搭、LongCat 及自定义接口） HTTPS POST JSON，OpenAI 兼容 /chat/completions 模型名称、翻译指令（系统提示）、待翻译文字 以 Authorization: Bearer 发送您填写的 API Key
Ollama（本机） HTTP POST JSON，发往您配置的地址 模型名称、翻译指令、待翻译文字 不附加密钥；使用回环地址时请求留在本机，远程部署则发往对应服务器

Google 与 MyMemory 以 GET 方式发送，文字会出现在请求地址中，可能被服务方的访问日志记录。远程自定义接口强制 HTTPS，HTTP 仅允许 localhost 与 127.0.0.1；接口地址不得包含账号密码、查询参数或片段。自定义接口域名需要您主动授权后才会请求。

使用 AI 服务时，翻译指令中会说明源语言与目标语言；若文字中含有受保护的术语或代码片段，指令会要求服务原样保留形如 ⟦YZY数字:数字⟧ 的内部标记。这些标记在本地生成与还原，整张术语表不会发送给服务。

模型与字体下载

  • OCR 模型来自 tesseract-ocr/tessdata_fast 仓库的固定 commit；导出字体来自 notofonts/noto-cjk 仓库的固定 commit（SIL Open Font License 1.1）。两者均通过 GitHub 原始资源地址（raw.githubusercontent.com）下载。
  • 下载前按对应来源申请访问权限；下载后校验 SHA-256 摘要与字节数，再保存到本机数据库。摘要不匹配的内容不会被使用。
  • 下载请求不携带 Cookie、不发送 Referer、不跟随重定向，也不附带 PDF 正文、页面图像或任何个人配置。下载服务仍会接收通常的网络连接信息。
  • 远程资源是模型与字体数据文件，不是可执行代码。扩展不加载远程脚本；PDF 与 OCR 引擎随扩展包提供，在本地运行。

连接测试

主动点击“测试连接”时，扩展向对应接口发送固定样例文字 Hello world（英语 → 简体中文）及必要认证信息，用于验证连通性与凭据有效性。测试不会发送您的网页或 PDF 内容。百度只有在当前这份 AppID 与密钥测试通过后才可被选择；凭据变化后旧测试结果立即失效。

Chrome 同步与本页面托管

  • 普通偏好可能经您的 Chrome 账号同步到同一账号的其他设备，详见第四节。API 密钥、术语表与请求策略不写入同步区。
  • 通过 GitHub Pages 访问本隐私网页时，会连接 GitHub 的托管服务，其日志规则由 GitHub 决定。本页面不加载统计脚本、远程字体或外部运行代码。

四、本机保存与 Chrome 同步

仅保存在本机的配置（chrome.storage.local）
各 AI 厂商的接口地址、密钥与模型；百度 AppID、密钥与连接验证记录；每服务的请求频率与并发策略；自定义术语表。术语表可主动导出为 JSON 文件。本机存储不等同于加密保险箱，详见第九节。
可能通过 Chrome 同步的偏好（chrome.storage.sync）
所选服务与 AI 厂商、源/目标语言、显示模式、译文样式（字体、字号、颜色、字重、行高、间距）、自动翻译开关、悬停翻译方式、悬浮球面板开关、快捷键启用状态，以及悬浮球位置、界面语言、配色与外观模式。这些字段不含密钥与文档内容，但可能同步到您使用同一 Chrome 账号的设备。
旧版凭据迁移
旧版本曾把凭据保存在同步区。首次读取时会迁移到本机，本机已有配置优先（包括您主动清空的密钥）；写入成功后删除同步区的旧字段。扩展无法直接控制 Chrome 同步服务此前已保留的历史副本。
PDF 人工修订与本机资源（IndexedDB）

六、日志与诊断

  • 开发源码带有可配置的主动日志（级别 off / error / warn / info / debug），输出到浏览器控制台，供本机排查使用。日志约定禁止包含原文、译文、密钥、完整请求对象与含敏感参数的地址。
  • 正式打包会在临时副本中强制关闭主动日志（production + off），并校验安装包；因此商店安装包默认不输出这些日志。开发源码的日志配置不会被打包流程修改。
  • 翻译耗时诊断只包含阶段名、任务与分片编号、服务标识、字符数与字节数、配置的限额、耗时毫秒数与 HTTP 状态码，不含文字内容、凭据、缓存键或账号信息。诊断只回传给发起请求的扩展页面，不发送到任何服务器。
  • 错误提示使用固定的中文分类说明，不直接透传第三方返回的原始正文。
  • 扩展不写入自建日志文件，也不上传日志。浏览器自身或网页产生的控制台输出不属于扩展的主动日志。

七、我们不做的处理

  • 不含广告、使用行为统计、分析或遥测代码，也没有自建数据采集服务器。
  • 不收集账号身份、姓名、邮箱、设备标识符或位置信息；扩展没有注册或登录流程。
  • 不读取或上传浏览历史、Cookie、书签、下载记录。
  • 不上传完整 PDF 文件、页面图像、OCR 位图或整页 HTML。
  • 不加载远程可执行代码；第三方引擎随扩展包提供，按需下载的是模型与字体数据文件。
  • 不主动把网页地址加入翻译请求，不把术语表整表发送给服务。

需要说明的例外：您选择的服务方会按其自身政策处理收到的文字与连接信息；Chrome 同步会按您的账号设置传输普通偏好；GitHub Pages 会按其托管规则记录本页面访问。这些不在扩展的控制范围内。

八、如何控制与清理

减少发送

  • 关闭“自动翻译”可停止新页面自动启动；当前页一旦开始仍会补翻，需点击取消停止。关闭悬停翻译或改回“需按 Shift”可避免鼠标停留触发发送。
  • 离开标签页或最小化窗口会暂停网页新发送，在途请求可能完成；返回后按页面状态继续。用户取消后不会自动恢复整页翻译。
  • 取消会清理本页排队任务，并尝试中止仅由本页使用的请求；其他页面仍依赖的共享请求会保留。已被服务方接收的数据无法通过取消撤回，仍可能被处理或计费。
  • 在 Chrome 扩展管理页可调整网站访问权限，或收回已授权的自定义接口、PDF 来源与资源下载来源。

删除本机数据

  • 设置页可清空或修改 AI 密钥、接口地址与模型，清空百度 AppID 与密钥（凭据变化会使旧验证记录失效），编辑或删除术语规则，恢复默认译文样式与行为偏好。
  • PDF 阅读器可删除已下载的 OCR 模型与导出字体；可恢复对应段落的机器译文或删除区域补译。“取消翻译”清除本页原位译文与修订，“重新翻译”清除本页旧结果后重新处理，两者都不删除独立编辑稿。
  • 关闭阅读器会释放临时文件字节与缓存；已保存的原位修订、独立编辑稿、模型与字体仍保留在本机数据库中，需要按上一条主动删除。
  • 卸载扩展会清除其 storage.local、storage.sync 中的扩展数据、IndexedDB 数据库与阅读页 localStorage。Chrome 同步服务此前已同步到其他设备或账号侧的副本，需由您在相应设备或账号设置中处理。
  • 主动导出的术语 JSON 与译文 PDF 是独立文件，需自行管理或删除；第三方服务已保存的数据需按各自政策申请删除。

九、保留期限与安全边界

  • 内存缓存有明确期限：成功译文最多 10 分钟、最多 256 条，失败冷却 30 秒，后台线程退出即清空；页面与阅读页内存在关闭后释放。
  • 本机持久化数据（密钥、术语表、请求策略、原位修订、独立编辑稿、下载的模型与字体、界面偏好）没有自动过期时间，会一直保留到您主动删除或卸载扩展。
  • 本机存储由浏览器与操作系统保护，但扩展未对密钥或修订内容做额外加密；同一设备上的其他程序或具备相应权限的人可能访问。请勿在共享设备上保存敏感凭据。
  • 远程接口强制 HTTPS，本机回环地址允许 HTTP。密钥在 AI 请求中以认证头发送，这是调用该服务的必要条件；百度密钥本身不发送。
  • 扩展不能控制服务方的保留期限、是否用于模型训练或是否计费。涉及敏感、机密或个人信息的内容，请自行评估后再选择服务与翻译范围。
