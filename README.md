# 页知译 · 网页双语翻译

[English](README.en.md) · [English privacy](docs/privacy-en.html)

页知译是 Chrome Manifest V3 翻译扩展，在网页原文下方显示译文，并提供独立的 PDF 阅读翻译器，适合外文网页、技术资料与 PDF 文档的双语阅读。

当前代码版本 **1.0.3**。代码版本不代表 Chrome 商店审核或发布状态，已安装版本可能与源码不同。

[核心特点](#核心特点) · [安装方式](#安装方式) · [快速使用](#快速使用) · [基本配置](#基本配置) · [隐私与安全](#隐私与安全) · [已知限制](#已知限制)

## 核心特点

- 保留网页原文与节点结构，支持双语对照和仅显示译文。
- 统一处理整页、单段、动态内容、开放式 Shadow DOM 和允许访问的 iframe。
- PDF 阅读、OCR、修订、编辑和导出在本机完成，翻译文字交给所选服务处理。
- 可选择多种翻译服务，通过技术术语表固定产品名和专业词汇的译法。
- 界面支持简体中文、繁体中文与英文，其他浏览器界面语言回退英文；界面语言、外观模式与主题配色独立于译文目标语言设置。

## 网页翻译

- 支持整页翻译、选中文字翻译，以及鼠标所在段落的 Shift 翻译与还原。
- 开始整页翻译后，随滚动、弹框和动态内容持续补翻；取消后恢复原文并暂停本页补翻。
- 支持开放式 Shadow DOM，以及 Chrome 允许访问的跨源、嵌套和相关空白 iframe；子框架随主页面开始或取消，不重复显示控制面板。
- 浏览器前进、后退恢复页面时保留已有译文与暂停意图。
- 提供 48 种语言选项，默认自动检测源语言，目标语言跟随浏览器界面语言；译文字体、字号、颜色、字重、行高和间距可调。
- 翻译提示只在快捷键已设置且已启用时显示实际按键组合，未设置时不显示。扩展建议为 Ctrl+Shift+Y，macOS 为 Command+Shift+Y，可在浏览器扩展的键盘快捷键页面调整。

## PDF 阅读与翻译

从扩展弹窗、设置页“翻译工具”或网页 PDF 链接进入独立阅读器。支持本地文件和经授权的在线 PDF 直链，单文件最多 **50 MiB**；可跳页、缩放、旋转、输入密码，并通过缩略图导航。

- 原文、译文与双语对照三种模式；双语右侧可选择原位译文或独立译文编辑器，原位预览支持同步滚动。
- 原位译文仅在安全排版检查通过时覆盖；无法放入的译文保留编号，可在“翻译检查”中定位。
- 原位修订可拖画、移动、缩放文字框，调整文字与字体样式，实时预览并在本机保存。
- 独立编辑器支持文字和段落排版、表格、图片、查找替换、撤销重做与本机保存。

| 导出方式 | 用途 |
| --- | --- |
| 原始 PDF | 保存完整源文件，不修改源字节 |
| 译文 PDF · 保留原版式 | 使用安全原位覆盖及已保存修订，无法放入的译文补充到附录 |
| 译文 PDF · 结构化阅读 | 按标题、段落、分栏、表格、代码和图形自动重排，必要时增加续页 |
| 导出本页编辑稿 | 通过浏览器打印保留独立编辑器的修改及其续页 |

自动译文导出包含已保存的原位修订，**不包含独立编辑稿改动**。译文可选当前页、自定义范围或全部页，一次最多 50 个源页面；缺译或部分完成时，需选择补译或保留未译内容。

## OCR 文字识别

主动开始 PDF 翻译后，扩展提取文字并在本机识别扫描页或混排区域，页面图像不上传翻译服务。单独修订只准备文字与坐标，不主动调用 OCR 或翻译服务。

英语、简体中文模型随扩展提供；繁体中文、日语、韩语、法语、西班牙语、德语、俄语、阿拉伯语模型可按需下载，经 SHA-256 校验后保存在本机，并可在阅读器中管理。

当前没有独立图片文件 OCR 入口；编辑器插入图片属于编辑功能。

## AI 提示词

在设置中选择七种内置翻译风格，或复制后通过六项参数和高级附加指令建立自定义模板。模板与最近 5 份历史只保存在本机，支持收藏及 JSON 导入导出。网页面板和 PDF 工具栏可为当前会话临时选择模板；已启动任务保持原快照。

本地提示词预览不发送请求；「翻译测试与对比」使用已配置的 AI 服务，可能产生 API 费用。普通翻译服务不受影响，停用提示词功能后恢复原有 AI 指令。

## 技术术语表

- 内置保护 Linux、RHCE、OpenShift、Kubernetes、Red Hat 等原名。
- 可添加固定译法，译法留空即保留原词；支持目标语言、大小写规则与 JSON 导入导出。
- 最多 500 条自定义规则，导入上限 256 KiB；导入会替换当前列表，需保存生效。
- 自定义规则优先于内置规则，长词与具体语言规则优先。规则只保存在本机，匹配与还原也在本地完成。

## 支持的翻译服务

| 服务 | 使用条件 |
| --- | --- |
| Google 翻译、MyMemory | 无需配置账号；可用性受网络与服务限制影响 |
| 百度翻译 | 填写 AppID、密钥，当前凭据通过“测试连接”后可选 |
| AI 云端预设 | 配置自己的密钥、接口与模型，使用 OpenAI 兼容接口 |
| 本机 Ollama | 先运行本机服务并准备模型，无需 API Key |
| 自定义 AI 接口 | 填写兼容接口地址、密钥与模型，并授权域名访问 |

AI 预设包括 OpenAI、DeepSeek、通义千问、智谱 GLM、Kimi、火山方舟、MiniMax、阶跃星辰、硅基流动、百度千帆、魔搭和 LongCat。预设模型不保证对每个账号都可用。

“已配置”只表示满足界面选择条件，不代表连接、模型或额度实时可用。使用自己的账号时，费用与数据处理规则由服务方决定。

## 安装方式

公开说明仓库不包含扩展源码或安装包，安装入口以维护者提供的商店链接或安装文件为准。尚未在本文确认商店地址；请勿将公开说明仓库作为扩展加载。

如已取得扩展安装文件或获准使用源码：

1. 将安装包解压到独立目录，或使用已有的项目源码副本。
2. 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目根目录。
4. 打开扩展设置页，在“翻译服务”中选择或配置服务。

加载源码无需构建，也无需 Node.js 或开发依赖。修改运行文件后需重新加载扩展、刷新网页，并重新打开设置页、弹窗和 PDF 阅读页。

## 快速使用

### 网页

| 操作 | 效果 |
| --- | --- |
| 点击可拖动的悬浮球 | 开始 / 取消当前页翻译，位置会记忆 |
| 悬停悬浮球 | 展开翻译面板、PDF、设置和反馈菜单，可在设置中关闭 |
| 鼠标停在段落上按 Shift | 翻译 / 还原单段，可改为直接悬停触发或关闭 |
| Ctrl+Shift+Y；macOS Command+Shift+Y | 翻译 / 取消当前页，可在 `chrome://extensions/shortcuts` 修改或禁用 |
| 右键菜单 | 翻译此页面 / 翻译选中文字 |

新安装默认关闭自动翻译。关闭该开关只影响新页面自动启动；已开始翻译的页面需点击取消才停止补翻，之后仍可主动 Shift 翻译单段。离开标签页或最小化窗口会暂停新发送，在途请求可能完成，返回后按页面状态继续。

### PDF

1. 打开本地 PDF，或输入最终在线直链并授权来源。
2. 确认服务和语言后点击“开始翻译”，按需切换阅读模式、检查结果或修订。
3. 选择导出方式与页码；需要保留独立编辑器改动时，使用“导出本页编辑稿”。

“停止翻译”保留成功结果；“取消翻译”清除本页原位译文与修订；“重新翻译”清除本页旧结果后重译。后两者均保留其他页结果和独立编辑稿，切换模式、缩放与旋转复用已有结果。

在线 PDF 请求不携带 Cookie、不发送 Referer、不跟随重定向；登录页、分享页或跳转链接请先下载，再从本地打开。

## 基本配置

| 设置位置 | 主要内容 |
| --- | --- |
| 基本设置 | 默认服务、源/目标语言、双语或仅译文模式 |
| 翻译服务 | AI 接口、密钥、模型；百度凭据与连接测试；每服务请求频率与并发 |
| 技术术语表 | 内置保护与自定义固定译法 |
| 界面设置 | 界面语言、外观模式与主题配色 |
| 显示样式 | 双语显示模式，以及译文字体、字号、颜色、字重、行高和段落间距，实时预览 |
| 行为偏好 | 自动翻译、悬停方式、悬浮球面板与快捷键开关 |
| 翻译工具 / 关于 | PDF 阅读器入口、版本与隐私摘要 |

“界面设置”中可分别选择界面语言、外观模式（跟随系统、浅色、深色）与主题配色。配色共 13 种，默认午夜青蓝，另有极简灰、流光蓝、松林绿、雾紫、暖砂、海湾青、玫瑰粉、日落橙、薄荷绿、琥珀金、樱桃红、靛青蓝。每种配色都有完整的明暗版本，主题卡片按当前外观以真实界面结构预览，同步应用于扩展浮层、弹窗、设置页、PDF 工具界面和打印预览工具栏，保留网页与文档纸张原色。旧主题配置继续兼容。悬浮球保持 32px，拖动至距左、右窗口边缘 256px 内松手才吸附，其他位置可自由停放并记忆；闲时半隐，悬停展开右侧弧形菜单，指针在球与菜单之间移动不会收起，右侧空间不足时临时左移，收起后归位。

远程 AI 接口必须使用 HTTPS；HTTP 仅允许本机 `localhost` 与 `127.0.0.1`。其他电脑上的 Ollama 属于远程接口。测试或启用时按域名申请访问权限，拒绝授权则不发起请求。

## 隐私与安全

- 待译文字由扩展后台直接发送给所选服务，没有自建翻译中转服务器；不主动把网页地址或整页 HTML 加入请求，文字本身可能包含敏感信息。
- 完整 PDF、页面图像、OCR 位图、编辑和导出排版在本机处理；模型与字体数据按需下载，引擎代码随扩展提供。
- 密钥、接口配置、术语和请求策略保存在本机；普通偏好可能经 Chrome 同步。PDF 修订、独立编辑稿、模型与字体保存在本机数据库，关闭阅读器不会删除已保存内容。
- 本机存储没有额外应用层加密；第三方收到的文字受其政策约束。取消无法撤回服务已接收的文字，也不保证免除费用。
- 自动采集跳过输入值、密码框、编辑区、代码与明确禁译区域；主动 Shift 可覆盖网页禁译标记，仍跳过输入、编辑区与代码。

完整的数据流、权限、存储、共享与清理说明以 **[隐私与数据说明](docs/privacy.html)** 为准，这是唯一维护的隐私正文。项目不包含广告、统计或遥测代码。


## 已知限制

- 不支持封闭式 Shadow DOM、Chrome 内置页面或系统弹框；iframe 受网站访问与沙箱限制。视频、音频和字幕翻译尚未接入。
- 语言选项不代表每个服务都支持；MyMemory 部分短文本需手动指定源语言。
- PDF 复杂表格、图文混排、行内公式、噪声、竖排和特殊字体可能保留原样或回退，不能保证任意 PDF 完整复刻版面。
- 编辑器中的图形以位图保留，不能逐个编辑图内元素；尚不支持固定页脚与自动续页编号。
- 导出字体覆盖有限，缺字或不支持的排版会阻止导出；汉字/假名与谚文可能需下载字体，粗斜体为模拟效果，与本机预览可能不同。
